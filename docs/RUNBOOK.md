# 市政审理值班操作

交班时先打开占道许可台账，记下页尾运行指纹。需要调整处置量时，在工作台输入已确认的复核名额（单），查看变更后的占道许可台账，再从「许可附件」核对相关环节。

没有加载到样例时，先检查 `/health`。若健康接口已恢复，刷新页面并重新提交本班额度。输入超限会得到 `INVALID_SCENARIO`，页面保留上一次有效结果。

复核记录可通过工作台下载。导出包含前台展示的全部批次结果及六个环节的证据，便于按运行指纹对照。

## 临时缺班重排

1. 在「缺班人员与分钟区间」按 `{"审理员": [起始分钟, 结束分钟]}` 填写缺班，多人可并列；人员必须是已发布班表内的审理员，区间端点为递增整数。
2. 点击「缺班重排」。裁决区先给汇总（保留原约、改派、退回主管协调、补位入班等数量），下方依次是告知凭据台账和逐单裁决。
3. 核对纪律：未受缺班冲击的预约显示「保留原约」且新班字段与原约一致；改派单有「改派告知」并在「替代凭据」列引用原告知，原告知仍留在台账内；退回单释放的席位才允许「补位入班」，补位单有独立「补位告知」。
4. 双签工单（三车道及以上或围挡不少于 400 米）的新班记录里首审、二审必须是两个不同的人。
5. 同一缺班重复提交应得到相同的重跑令牌和裁决，不会新增席位或凭据；输入非法时页面提示 `INVALID_ABSENCE`，已发布班表不变。
