# 占道工单逾期审理 · 字段与计算

本项目使用确定性模拟业务数据。所有时间均以业务台账指定粒度解析。

## 数据文件与时钟

许可流水带单号、申报主体、道路、材料、占道范围、受理及录入时钟和修订，只有在截面可见的修订参与审理。工作日历带辖区和半开时段，条例暂停和补件暂停合并后扣除交集，周休日自然不累计。已使用分钟超过法定配额时判定为已经逾期，恰在法定期限不视为超时。

## 训练与审理分派

特征包括已用分钟比例、围挡长度、车道、补件数量、同区列队压力、道路等级及应急属性。训练样本严格按结案时钟切分，普通样本和逾期正例的损失权重不同。带 L2 惩罚的二元逻辑回归随后在独立时间段内作分桶保序校准，每桶保留样本数量并对无根据的体量拒绝自动分级。在审理台账里法定时钟和材料优先于模型可能性。

`capacity` 表示本轮可安排的复核许可数，默认 8。现场抢修允许补件和审批并行，大规模占道须不同首审和二审；每人受辖区、技能、重叠休息及当班最大件数影响。留出估计和已观测回执计算 Brier 误差、并列分数平均精度与空桶。
