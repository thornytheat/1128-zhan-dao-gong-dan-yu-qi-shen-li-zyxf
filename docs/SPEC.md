# 占道工单逾期审理 · 字段与计算

本项目使用确定性模拟业务数据。所有时间均以业务台账指定粒度解析。

## 数据文件与时钟

许可流水带单号、申报主体、道路、材料、占道范围、受理及录入时钟和修订，只有在截面可见的修订参与审理。工作日历带辖区和半开时段，条例暂停和补件暂停合并后扣除交集，周休日自然不累计。已使用分钟超过法定配额时判定为已经逾期，恰在法定期限不视为超时。

## 训练与审理分派

特征包括已用分钟比例、围挡长度、车道、补件数量、同区列队压力、道路等级及应急属性。训练样本严格按结案时钟切分，普通样本和逾期正例的损失权重不同。带 L2 惩罚的二元逻辑回归随后在独立时间段内作分桶保序校准，每桶保留样本数量并对无根据的体量拒绝自动分级。在审理台账里法定时钟和材料优先于模型可能性。

`capacity` 表示本轮可安排的复核许可数，默认 8。现场抢修允许补件和审批并行，大规模占道须不同首审和二审；每人受辖区、技能、重叠休息及当班最大件数影响。留出估计和已观测回执计算 Brier 误差、并列分数平均精度与空桶。

## 缺班重排与告知凭据

开班前出现审理员临时缺班时，重排只在已发布班表上裁决，不整体推翻：

- 已告知申报人的预约，只要其首审或二审时段不与缺班区间相交，一律保留原约，不得悄悄挪动，也不产生新告知。
- 与缺班相交的预约进入改派：在辖区、技能、班内时段和双签约束内挑选候选，优先选出能在法定截止分钟前完审的组合；时限内无组合时取最早完审组合，并在裁决依据中注明。
- 班内无法安置的预约退回主管协调，同时释放一个补位席位。释放席位只能给本班基线尚未安排的工单，补位顺序仍按应急、是否已逾期、法定剩余分钟、校准概率和许可号排队；材料未齐的非应急工单不得占补位席位。
- 需双签（三车道及以上或围挡不少于 400 米）的工单，改派或补位后仍须两名不同审理员在各自班内时段完成。
- 告知凭据台账只追加、不覆盖、不删除。首版预约告知、改派告知和补位告知按内容生成凭据号；改派告知以 `supersedes` 指向原告知，原告知始终保留可查。
- 同一缺班事实重跑得到完全一致的新班表、裁决和重跑令牌；相同告知内容去重，不重复占位、不重复告知。缺班输入（人员须在班表内、时段为两个递增整数分钟）非法时拒绝重排，已发布班表不变。

`POST /api/reissue` 接收 `{"capacity": 8, "absences": {"审理员": [起, 止]}}`，`capacity` 省略时取默认 8；输入非法返回 `INVALID_ABSENCE`。
